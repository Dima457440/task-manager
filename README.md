# Task Manager

Консольное приложение для управления задачами.

## Возможности
- ✅ Добавление задач
- ✅ Просмотр всех задач
- ✅ Отметка задач как выполненных
- ✅ Удаление задач
- ✅ Сохранение задач в файл

## Технологии
- Python 3.8+
- JSON для хранения данных
